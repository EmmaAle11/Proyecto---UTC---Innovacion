Campo de texto de formularios (login, búsqueda, notas del pedido).

```jsx
<Input label="Correo institucional" placeholder="tu@utc.edu" leftIcon={<i data-lucide="mail" />} />
<Input label="Código" error="Código incorrecto" />
```

Props: `label`, `hint`, `error`, `leftIcon`, + atributos nativos de `<input>`.
